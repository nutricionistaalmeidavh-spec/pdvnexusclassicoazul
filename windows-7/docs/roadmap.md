# Roadmap

## Norte

Construir uma software factory que permita abrir um novo sistema em dias, e nao em meses.

## Sprint 0

- definir nomenclatura
- estruturar monorepo
- registrar arquitetura base
- definir template de modulo

## Sprint 1

- shell do app desktop
- app React principal
- pacote `database`
- pacote `core`
- pacote `ui`

## Sprint 2

- autenticacao local
- permissoes
- layout base
- componentes de formulario
- tabela generica

## Sprint 3

- CRUD generico
- importador Excel
- exportador Excel
- PDF
- upload
- historico

## Sprint 4

- modulo `ai`
- modulo `documentos`
- modulo `crm`
- modulo `financeiro`
- modulo `balanca`
- modulo `dashboard`

## Sprint 5

- app `meu-engenheiro`
- adaptacao dos modulos ao dominio de engenharia
- refinamento dos templates para novos nichos

## Sprint 6

- dashboards por nicho com identidade visual propria
- demo de dashboard para PDV
- demo de dashboard academico para Sr. Engenheiro
